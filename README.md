# habit-tracker-
Habit tracker for daily habit tracking

**Open the app:** https://chs14gh.github.io/habit-tracker-/

## Use it on your iPhone
1. Open the link above in **Safari**.
2. Tap **Share → Add to Home Screen**.
3. Always open the app from that home-screen icon.

Your habits are saved on your own phone. Nobody else can see them.
Tap **⋯** in the app to copy a backup code now and then.

## Features
- Pastel habit squares with a 🔥 streak count and the last 7 days
- A calendar for each habit (tap past days to fill them in)
- Any emoji from your keyboard, and any colour from the colour wheel
- Dark starry-night theme

## Home-screen widget (optional, needs the Scriptable app)
1. Install **Scriptable** from the App Store.
2. Create a new script named exactly **Habit Tracker** and paste in
   [`widget/Habit Tracker.js`](widget/Habit%20Tracker.js).
3. In the app, open a habit's 📅, tap **☆ Show on widget**, then **Update widget**.
4. Add a small **Scriptable** widget to your home screen, long-press it →
   **Edit Widget** → Script: **Habit Tracker**, When Interacting: **Open URL**.
